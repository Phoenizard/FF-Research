# 段间传递：同分辨率段变长后，交给下一段的张量

来源：tmp/depth_diag/input_probe.py（2026-11-17），未在仓库代码上重跑。CIFAR-100，种子 1，checkpoint 为正式结果。

## 问题

32 层每段的层数是 16 层的两倍。段变长后，交给下一段的张量是否更难学？

## 做法

- 冻结最终 checkpoint，eval 模式（无 Dropout，TTGS 用期望系数）。在第 1、2、3 段末尾切开，取该层传递输出（即下一层的输入）。
- 切点：16 层为 L4 / L8 / L10，32 层为 L8 / L16 / L20；同一切点两边的通道数和分辨率相同。
- 在这个张量上从零训练同一个小网络：Conv3×3(C→256)–BN–ReLU–Conv3×3(256→256)–BN–ReLU–GAP–Linear(100)。
- checkpoint：results/cifar100/{16-depth, 32-depth-v2}/{TTGS, TTG, Global-BP}/seed1。

## 结果（测试 %；括号内为与 16 层之差）

| 切点 | TTGS 16 → 32 | TTG 16 → 32 | BP 16 → 32 |
|---|---|---|---|
| 第 1 段后（100×16×16） | 53.29 → 52.54（−0.75） | 53.14 → 50.10（−3.04） | 55.96 → 54.03（−1.93） |
| 第 2 段后（200×8×8） | 59.64 → 58.78（−0.86） | 59.49 → 53.19（−6.30） | 61.93 → 57.51（−4.42） |
| 第 3 段后（400×4×4） | 63.09 → 62.66（−0.43） | 62.03 → 54.70（−7.33） | 62.18 → 52.94（−9.24） |

最后一轮训练 %：TTGS 60.29 → 59.55、73.26 → 70.87、90.18 → 86.21；TTG 59.99 → 55.02、72.05 → 61.68、86.29 → 71.40；BP 64.82 → 64.55、86.67 → 75.25、99.47 → 94.09。

## 结论

- 没有跳连流的 TTG，段变长后交给下一段的张量明显变差，且越往后越大（−3.0、−6.3、−7.3）。
- TTGS 在三个切点只低 0.4～0.9，跳连流保住了段间传递的信息。
- BP-32 的中间张量也变差，第 3 段后低 9.2。
